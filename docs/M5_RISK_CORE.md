# M5-RISK-001：独立风险评估基础

该模块是面向任意证券与行业的**独立、确定性风险计算层**，不依赖海南橡胶或天然橡胶的专用指标。

## 本次范围

- `HypotheticalPosition`：证券标识、资产类别、行业/风险分组、持仓假设市值、币种。
- `RiskLimits`：单只证券最大权重、行业最大权重、风险资产总权重、最大历史回撤阈值。
- `EquityObservation`：带日期的组合权益假设历史；必须排序，禁止未来样本与重复日期。
- `StressShock`：显式指定证券价格冲击，产生组合冲击金额、冲击收益率和冲击后价值，标记为 `scenario_assumption`。
- `assess_hypothetical_risk`：计算组合总价值、现金比例、最大单资产/行业权重、总风险敞口、最大回撤以及阈值触发情况。

## 数据可信度

**所有输入都是 hypothetical/synthetic，不声称是实时或已经核实的真实持仓。** 当前代码只有纯函数和单元测试，没有连接 OTW，也没有下单、调仓、投票或自动执行。

历史权益曲线缺失时，`max_drawdown=null`，绝不由持仓快照凭空推断历史回撤。压力情景不是预测。限制项触发仅代表风险条件命中，不代表买入或卖出建议。

该版本仅支持非负持仓、市值同币种、非负现金的 long-only 分析。对混合币种、空头、杠杆或不合理冲击明确拒绝，而不是静默净额化。尚无汇率换算、流动性、相关性、VaR、尾部风险或交易成本模型。禁止将其标记为全面风控系统。

## 安全与下一阶段

- 所有输出的 `eligible_for_trading=false`；该字段不可由调用者打开。
- 不接入任何 Web API 写操作，不连接 OTW，不修改现有策略或交易流程。
- 等待后续经过来源、时间、单位和用户授权校验的只读持仓 resolver，才能用于现实投资组合风险评估。
- 下一增量在数据 provenance 审计完成后，再添加只读风险 API、真实持仓适配与最大回撤/集中度历史验收。

验收：不同产业及 ETF 的合成仓位可通过相同纯函数；测试覆盖资金权重、行业聚合、冲击、最大回撤、未知证券、未来数据、负市值与混合币种。CI 通过后方可合并。
